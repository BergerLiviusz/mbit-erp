# Kontrolling – GINOP demo forgatókönyv

1. **Dashboard megnyitása** – Kontrolling → Dashboard, modul szűrő, Frissítés  
2. **KPI szűrés** – válasszon „CRM” vagy „LOGISTICS” modult  
3. **CRM pipeline riport** – Riportok → `crm.pipeline` → XLSX  
4. **DMS OCR riport** – `dms.ocr` export  
5. **HR lejárati riport** – `hr.medical` export  
6. **Készlet riport** – `logistics.stock` export  
7. **Ad-hoc riport** – Ad-hoc → LOGISTICS, mezők, XLSX  
8. **Export CSV/XLSX** – minden riportnál lokális letöltés  
9. **Audit napló** – Rendszer / CRM audit → export események ellenőrzése  

**Előfeltétel:** controlling modul engedélyezve a csomagban; backend indulás után permission sync automatikus.
